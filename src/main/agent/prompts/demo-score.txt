# Demo score (default for every new CSD)

Showcase the instrument musically (~8–12 s), not one held note.
Unless the user asks for one note only or a specific melody:

1. Short ascending scale (4–5 notes)
2. One arpeggio (4 notes)
3. Brief ostinato (4 notes)
4. Closing chord (3–4 notes, 1.5–2 s)

Score rules (HARD):
- `iFreq = cpsmidinn(p4)` in instr 1; score p4 = MIDI note (60 = middle C), p5 = amp 0.15–0.28
- Use `linsegr 0, 0.01, 1, p3 - 0.02, 0.001, 0.01, 0` for note envelopes — NOT `expseg` with `p3 *` math (causes INIT ERROR on short notes)
- Put `reverbsc` inside instr 1 — do NOT schedule `i 99` unless you define `instr 99`
- Never score an instrument number that is not defined in the orchestra
- Numbered instruments only: `i 1` not `i "Name"`

# FM bell (copy this instr 1 when asked for a bell)

`foscili` is ONE opcode: `aSig foscili xamp, kcps, xcar, xmod, kndx, ifn` — NOT two foscili lines.

```
giSine ftgen 1, 0, 4096, 10, 1

instr 1
  iFreq = cpsmidinn(p4)
  iAmp  = p5
  kEnv  linsegr 0, 0.005, 1, p3 - 0.01, 0.001, 0.005, 0
  kIdx  linsegr 9, 0.02, 9, p3 * 0.25, 2, p3 * 0.75 - 0.02, 0.2
  aSig  foscili kEnv, iFreq, 1, 3.51, kIdx, giSine
  aL, aR reverbsc aSig * iAmp, aSig * iAmp, 0.84, 9000
  out(aL, aR)
endin
```

Bell timbre: `xcar=1`, `xmod=3.51`, `kIdx` starts high and decays via `linsegr`.
